HOW THE PROGRAM WORKS 仕組み/申し込み方法

① 選手による支援の申し込み

選手登録を済ませた後、以下のフォームから支援の申し込みが可能になります。

選手用申請フォーム

支援金額：出場費、交通費、宿泊費の合計の概算を上限とする支援希望金額の申請が可能です。

申請内容の公開：選手が申請した内容のうち、選手名、レート、選手からの一言は、運営が当ページで公表します。また、選手のメールアドレスなどの連絡先については、運営から選手指名型を申し込んだ支援者の方に共有させていただきます。

申請後の辞退：支援を申し込んだ後、大会への参加を辞退する場合は、早急に交通手段及び宿泊のキャンセルを行い、運営に通知してください。キャンセル料が発生した場合は、その旨も合わせて通知してください。

年齢制限：18歳未満の方は保護者の同意が必要です。

② 選手指名型（特定の選手への支援）

選手登録を済ませた後、以下のフォームから支援の申し込みが可能になります。
支援者様が特定の選手を指名し、直接支援を行う方法です。

支援者用申請フォーム

やり取り：支援者様と選手間で直接連絡・金額交渉・送金を行っていただきます。（大会運営はマッチングの場のみを提供します）

指名の条件：先着順となります。また、希望額を超える過剰な支援はできません。

複数指名：1人の支援者様が複数の選手を指名することは可能です。

年齢制限：18歳未満の方は申請できません。

[ 選手指名型支援フロー ]

  1. 支援者が選手を指名して申請
  2. 大会運営が選手と支援者をマッチング
  3. 支援者と選手が直接やり取り（支援額の交渉・調整などは当事者間で実施）
  4. 選手へ直接送金送金完了後、支援額を大会へ報告（10/9 FRI. 23:59まで）

③ 個人協賛型（大会への協賛・選手指定なし）

特定の選手を指定せず、大会への個人協賛金をご支援していただく方法です。
集まった個人協賛金は、大会運営より「選手の参加費用補助」として割り当てられます。

支援者用申請フォーム

分配ルール：指名を受けなかった選手及び指名を受けたが希望額に達していない選手を対象に、申込時点のレート順に補助を実施します。

協賛金額：最低・最高額の設定はございません。任意の金額でご協力いただけます。

分配スケジュール：10月3日より順次分配を開始します。

年齢制限：18歳未満の方は申請できません。

[ 個人協賛型支援フロー ]

  1. 支援者が個人協賛(選手指定なし)で申請
  2. 大会運営が補助対象選手を決定（補助対象選手の選定について＞レートを高い順に補助）
  3. 大会運営が対象選手へ参加費用を補助（送金）

NOTE 注意事項

支援者様および選手の皆様は、必ず以下の注意事項をご確認の上お申し込みください。

全般・共通ルール

トラブルについて：選手と支援者間でのトラブル（連絡不通・未送金等）に関して、大会運営は一切の責任を負いません。

返金について：振込後の協賛金・支援金の返金には原則応じられません。

満額の保証：本制度は、選手の希望額が必ず集まることを保証するものではありません。

希望額の上限：選手は申請した希望額を超えてお金を受け取ることはできません。

支援者様のリターン：支援者様につきましては、「WEBサイト・配信画面へのクレジット掲載」をさせていただきます。

選手指名型に関する特記事項

連絡、交渉について：トラブルを未然に防ぐため、選手の都合により大会参加を辞退する場合など、細かい条件まで事前にご調整いただくことをお勧めいたします。

振込完了時の連絡：大会運営は各選手の支援のステータスを管理し、支援者様のクレジットを掲載するため、支援者様は選手への支援金の振込が完了したら大会運営にご連絡ください。

個人協賛型（大会協賛）に関する特記事項

支援成立条件：支援者様が申請後、指定期日までに入金が確認できない場合、支援は未成立となります。

余剰金の扱い：選手の希望額を満たす個人協賛金が余った場合、その余剰分は大会運営費に充当させていただきます。

振込手数料：協賛金をお振り込みいただく際の振込手数料は、支援者様のご負担となります。

不参加・中止時の対応：
支援決定後に選手が欠場した場合、キャンセル可能な交通費・宿泊費を精算し、返金された分は個人協賛金の原資へ戻します。
天候不順・天災等で大会が中止となった場合、精算・キャンセルにより回収できた費用は可能な限り個人協賛者様へ返金いたします。
事故や交通トラブル等で現地に到着できなかった場合、発生済みの実費（航空券・ホテル代等）についての返金対応は不要とします。
本制度は法律その他を遵守するために慎重に制度設計をしておりますが、不備があった場合の対応等につきましては、別途ご連絡させていただきます。
