INTRODUCTION イントロダクション

PLAYER PATRON PROGRAMは、RASHINBANに出場する選手の出場費・交通費・宿泊費を支える制度です。

パトロンは、特定の選手を選んで直接支援する「選手指名型」と、選手を指名せず、大会運営のルールに基づいて選手支援金を配分する「選手指名なし型」のいずれかを選択できます。

HOW THE PROGRAM WORKS 仕組み/申し込み方法

① 選手による支援希望の申請

選手登録を済ませた後、以下のフォームから支援の申し込みが可能になります。

選手用申請フォーム

支援金額：出場費、交通費、宿泊費の合計の概算を上限とする支援希望金額の申請が可能です。

申請内容の公開：選手が申請した内容のうち、選手名、レート、選手からの一言は、運営が当ページで公表します。また、選手のメールアドレスなどの連絡先については、運営から【選手指名型】を申し込んだパトロンの方に共有します。

申請後の辞退：支援を申し込んだ後、大会への参加を辞退する場合は、早急に交通手段及び宿泊のキャンセルを行い、運営に通知してください。キャンセル料が発生した場合は、その旨も合わせて通知してください。

未成年者の申請： 18歳未満の選手が申請する場合は、保護者の同意が必要です。

② 選手指名型（特定の選手への直接支援）

パトロンが支援したい選手を指名し、直接支援金を送る方法です。

パトロン申込フォーム

連絡・送金：パトロンと選手の間で直接連絡・金額交渉・送金を行っていただきます。（大会運営はマッチングの場のみを提供します）

申込順：選手への支援申込みは、申込順に受け付けます。また選手が申請した支援希望額を超える支援はできません。

複数選手への支援：1人のパトロンが複数の選手を指名して支援することも可能です。

年齢制限：18歳未満の方は、パトロンとして申し込むことはできません。

[ 選手指名型の支援フロー ]

  1. パトロンが支援する選手を指名して申込む
  2. 大会運営がパトロンと選手をマッチング
  3. パトロンと選手が直接やり取りを行う（支援額・送金方法などは当事者間で確認を行う）
  4. パトロンが選手へ直接送金する送金完了後、支援額を大会へ報告（10/2 FRI. 23:59まで）

③ 選手指名なし型(大会運営による配分)

特定の選手を指名せず、選手全体の参加を支援する方法です。パトロンからの選手支援金は、大会運営が定めるルールに基づき、支援対象選手へ参加費用支援金として配分します。

パトロン申込フォーム

配分ルール：選手指名型による支援を受けていない選手、および支援を受けていても支援希望額に達していない選手を対象として、選手の支援希望申請時点のレートが高い順に配分します。

選手支援金額：最低額・最高額の設定はございません。任意の金額でお申し込みいただけます。

配分開始日：10月3日から、対象選手への配分を順次開始します。

年齢制限：18歳未満の方は、パトロンとして申し込むことはできません。

[ 選手指名なし型の支援フロー ]

  1. パトロンが「選手指名なし型」で申し込む
  2. パトロンが指定期日までに大会運営へ選手支援金を送金する
  3. 大会運営が支援対象選手と配分額を決定（支援対象選手の選定は、レートが高い順）
  4. 大会運営から対象選手へ参加費用支援金を送金

NOTE 注意事項

パトロンおよび支援を希望する選手の皆様は、必ず以下の注意事項をご確認のうえ、お申し込みください。

共通の注意事項

トラブルについて：選手とパトロン間でのトラブル（連絡不通・未送金等）に関して、大会運営は一切の責任を負いません。

返金について：振込後の選手支援金の返金には原則応じられません。

支援希望額の保証：本制度は、選手の申請した支援希望額が必ず集まることを保証するものではありません。

希望額の上限：選手は申請した支援希望額を超えて選手支援金を受け取ることはできません。

パトロンの皆様への御礼：ご支援への感謝を込めて、ご希望のお名前またはハンドルネームを、RASHINBAN公式WebサイトおよびDAY 2配信のエンドロールに掲載します。

選手指名型の注意事項

支援条件の確認 ：トラブルを未然に防ぐため、選手の都合による出場辞退、大会中止、交通機関の運休その他の事情が生じた場合の取扱いについて、パトロンと選手の間で事前に確認していただくことを推奨します。

送金完了報告：大会運営は各選手の支援のステータスを管理し、パトロンのクレジットを掲載します。選手への支援金の送金が完了したら、パトロンから大会運営にご報告ください。

選手指名なし型の注意事項

申込成立条件：申込み後、指定期日までに選手支援金の入金が確認できない場合、申込みは未成立となります。

未配分金の扱い：支援対象選手の支援希望額を満たした後に未配分金が生じた場合は、RASHINBAN 2026の大会運営費に充当します。

振込手数料：選手支援金をお振り込みいただく際の振込手数料は、パトロンのご負担となります。

選手の欠場・大会中止時の対応：
支援決定後に選手が欠場した場合、出場費・交通費・宿泊費等のうち、キャンセルまたは返金が可能な費用を精算します。回収できた金額は、選手指名なし型の未配分金へ戻します。
天候不順・天災等で大会が中止となった場合、費用の精算・キャンセルによって回収できた金額を、可能な限り各パトロンへ返金します。
事故や交通トラブル等で会場に到着できなかった場合、発生済みの実費（航空券・ホテル代等）については、原則として返金の対象となりません。 返金対応は不要とします。
本制度は法律その他を遵守するために慎重に制度設計をしておりますが、不備があった場合の対応等につきましては、大会運営から対象となるパトロンおよび選手へ個別にご案内します。
